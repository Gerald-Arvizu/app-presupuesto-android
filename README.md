# Aplicación Móvil de Presupuesto

Aplicación Android desarrollada en Kotlin para el registro y control de ingresos y gastos.

## Funcionalidades
- Autenticación de usuarios
- Registro de ingresos y gastos
- Visualización de balances
- Consumo de API REST

## Tecnologías
- Kotlin
- Arquitectura MVVM
- API REST
- .NET
- SQL Server
